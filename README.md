One word for our Wi-Fi: **peekaboo**. Home Wi-Fi plays peekaboo — there one minute, gone the next, back again before you can even complain about it. The funniest and truest description of Wi-Fi as we actually live it.

## Run it

```sh
python3 main.py
```

It prints the word and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
